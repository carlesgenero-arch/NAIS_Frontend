# Poppins

Official Google Fonts Poppins v24, normal weights 400 and 700, latin and latin-ext subsets.
Source: https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap
License: SIL Open Font License 1.1 (see OFL.txt).

Self-hosted WOFF2 files avoid external font requests during build and browsing. Angular fingerprints the files referenced from src/styles.css.
Poppins has no condensed face here; no artificial horizontal scaling is applied.
